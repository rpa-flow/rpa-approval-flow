# Especialistas

Estes arquivos complementam o `AGENTS.md`; não são prompts para executar todos os papéis em toda tarefa.

O coordenador escolhe somente os especialistas necessários e informa: objetivo, escopo, caminhos relevantes, restrições e saída esperada. Cada especialista lê `AGENTS.md`, seu arquivo de papel e apenas as fontes de verdade pertinentes.

Ordem comum para features grandes:

`PM → Arquiteto/Designer → Backend + Frontend → QA`

Para tarefas pequenas, pule papéis sem trabalho real. O coordenador integra decisões, resolve conflitos e é o único responsável pela entrega final.
